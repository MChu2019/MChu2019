Project Overview & Objectives

What it is: Pipeline collecting, cleaning, storing, analyzing job-market data.

What we built: Python cleaning functions, schema transformations, validation checks.

Assumptions & limits: API coverage is partial; Kaggle data supplements gaps.

My role: Designed data cleaning logic and supported ETL implementation.

Problem-solving approach: Iterative debugging; reusable functions; schema-first design.

🧩 Data Sources & Technology Stack

  • Use job APIs and Kaggle datasets
  • PostgreSQL database hosted on Aiven
  • Python, Pandas, SQLAlchemy for data processing

🔄 ETL Pipeline & Workflow

  • Extract data via API and datasets
  • Clean, normalize, and transform unstructured text
  • Load fact and dimension tables into database

📊 Analysis & Visualizations

  • Identify core data engineering skills
  • Analyze salary trends by company and country
  • Generate word clouds and salary boxplots

🚀 Key Learnings & Future Enhancements

  • What we achieved: Insights into core data/tech skills, salary variations, and top hiring countries.
  • What I learned: Handling API constraints, importance of data quality, and translating raw data into business-ready insights.
